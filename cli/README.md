# Aegis CLI

Secure command-line interface for managing Aegis.net DDoS protection.

## Features

- **Multi-layer Authentication**: SSH keys + TOTP 2FA + IP whitelisting
- **Complete Management**: Domains, rate limiting, protection levels
- **Audit Logging**: Track all configuration changes
- **Secure by Design**: CLI-only access to critical operations

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Setup Authentication

Run the 2FA setup wizard:

```bash
python setup_2fa.py
```

This will:
- Generate SSH keys (~/.ssh/aegis_cli)
- Create TOTP secret for 2FA (~/.aegis/totp_secret)
- Show QR code for Google Authenticator

### 3. Register Your Public Key

Send your public key (`~/.ssh/aegis_cli.pub`) to the Control Plane administrator to add to authorized keys.

### 4. Connect

```bash
python aegis_cli.py connect <control-plane-host>
```

Enter your TOTP code when prompted.

## Usage Examples

### Domain Management

```bash
# List domains
python aegis_cli.py domain list

# Add domain
python aegis_cli.py domain add example.com --origin https://origin.example.com --protection 3

# Remove domain  
python aegis_cli.py domain remove example.com
```

### Rate Limiting

```bash
# Configure rate limits
python aegis_cli.py ratelimit set example.com \
  --rps 1000 \
  --rpm 50000 \
  --per-ip-rps 10 \
  --per-ip-rpm 500 \
  --burst 20

# View configuration
python aegis_cli.py ratelimit show example.com
```

### Protection Levels

```bash
# Set protection level (1-5)
python aegis_cli.py protection set example.com 3
```

### Statistics & Monitoring

```bash
# View domain stats
python aegis_cli.py stats example.com

# View audit log
python aegis_cli.py audit
```

## Architecture

```
CLI Client (Your Machine)
    ↓ SSH Key + TOTP
    ↓ IP Whitelisted
Control Plane
    ↓ JWT Session Token
    ↓ Redis (Config Storage)
Edge Nodes
    ↓ Apply Rate Limits
Protected Origin
```

## Requirements

- Python 3.11+
- Google Authenticator or compatible TOTP app
- SSH key pair (generated by setup script)
- Whitelisted IP address

## Troubleshooting

### "SSH key not authorized"
Contact administrator to add your public key.

### "Invalid TOTP token"
- Check system time is synchronized
- Wait for next TOTP code

### "IP address not whitelisted"
Contact administrator to add your IP.

### "Session expired"  
Reconnect: `python aegis_cli.py connect <host>`
